# Marco Estores e Persianas

Landing page estática responsiva em HTML, Tailwind CSS (via CDN), CSS e JavaScript. Inclui a logótipo e fotografias reais fornecidas pelo cliente, convertidas para WebP para melhorar o carregamento.

## Abrir localmente

Abra `index.html` no navegador. Para testes completos, use um servidor local, por exemplo `python3 -m http.server 8080` e aceda a `http://localhost:8080`.

## Publicar no GitHub Pages

1. Crie um repositório GitHub.
2. Envie `index.html`, `style.css`, `script.js` e a pasta `assets` para a raiz.
3. Em Settings > Pages, selecione Deploy from a branch, `main`, `/ (root)`.
4. Aguarde a publicação.
